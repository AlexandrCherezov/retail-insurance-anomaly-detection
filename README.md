# Анализ выборки физических лиц на наличие аномалий и значимых зависимостей в страховании КАСКО 🚗🛡️

Проект посвящен комплексному разведочному анализу данных (EDA) клиентской базы физических лиц с целью выявления скрытых паттернов, аномалий и факторов, влияющих на наличие или отсутствие полиса КАСКО.

### 🎯 Бизнес-задача
Анализ профиля розничных клиентов страховой компании, сегментация выборки, обнаружение аномальных выбросов в данных и поиск статистически значимых зависимостей для оптимизации кросс-продаж и андеррайтинга.

### 🛠 Технологический стек
* **Язык программирования:** Python
* **Библиотеки анализа данных:** Pandas, NumPy, SciPy (статистические критерии)
* **Визуализация:** Matplotlib, Seaborn, Plotly (кастомные гистограммы распределений, матрицы корреляций, графики плотности)
* **Среда разработки:** Google Colab / Jupyter Notebook

### 🚀 Ключевые этапы исследования
1. **Предобработка и очистка данных:** Анализ пропусков в признаках выборки розничных клиентов страховой компании, выявление аномальных записей, проверка на логическую согласованность данных.
2. **Разведочный анализ (EDA):** Анализ распределения непрерывных и категориальных признаков. Построение матриц корреляции, графиков плотности распределения, ящиков с усами (boxplot) и кастомных гистограмм в разрезе клиентов с КАСКО и без него.
3. **Поиск аномалий и статистический анализ:** Проверка статистических гипотез с помощью критериев для оценки значимости различий в подвыборках. Локализация аномальных выбросов (например, нетипичный возраст, стаж, параметры авто), которые могут искажать результаты кросс-продаж или андеррайтинга.
4. **Оценка факторов и зависимостей:** Поиск ключевых признаков и скрытых закономерностей, сильнее всего коррелирующих со склонностью физических лиц к покупке полиса КАСКО.

### 📈 Результаты и выводы
* **Качество данных и логирование:** Локализованы системные пропуски и нетипичные выбросы в признаках. Обоснована критичность исправления логики сбора данных на входящем потоке для минимизации «грязных» данных.
* **Выявление закономерностей выборки:** Определены математически значимые интервалы концентрации и паттерны поведения клиентов. Обнаружены скрытые зависимости между социально-демографическими параметрами физлиц и вероятностью наличия страховки.
* **Бизнес-ценность:** Подготовлены выводы для коммерческого и продуктового блоков страховой компании, позволяющие точнее сегментировать розничную базу для таргетированных кросс-продаж и оптимизировать подходы к андеррайтингу рисков.
